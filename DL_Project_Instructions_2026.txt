1 Introduction
The goal of this data challenge is to explore and apply machine learning techniques to a real- world classification problem involving social media behavior. Specifically, this challenge focuses on the ability to predict a user's social role-either an Influencer or an Observer-based solely on the content of their tweets. Influencers are characterized by a high-leverage, asymmetrical network (a high follower-to-following ratio), while Observers maintain a more balanced, reciprocal network. Intuitively, Influencers are users who tend to accumulate a large audience and broadcast content widely, whereas Observers are users who engage in reciprocal conversations and build more balanced social interactions. This distinction creates a rich opportunity to study how language usage reflects underlying social strategies, and to design models capable of detecting these roles from text and general user features alone.

You are provided with a dataset in which each row corresponds to a single tweet, and each tweet is labeled with a binary value: 1 if it was authored by an Influencer, and 0 if it was authored by an Observer. While individual users may have multiple tweets, the challenge is structured to allow predictions based on a single tweet, emphasizing the ability of models to capture role-specific
language patterns in isolation. This setup introduces challenges related to text preprocessing, feature extraction, and the selection of appropriate modeling strategies.

The task encourages participants to experiment with a variety of approaches, ranging from traditional deep learning models such as multilayer perceptrons and recurrent neural networks, to modern deep learning techniques including transformers and language models fine-tuned for classification. Effective solutions will need to carefully consider the trade-offs between model complexity, interpretability, and generalization performance, while handling the variability and sparsity inherent in social media text. Hyperparameter tuning, regularization strategies, and thoughtful feature engineering will all play a key role in developing robust models capable of distinguishing between Influencers and Observers.

3 Provided Source Code
You are provided with two baseline classifiers, written in Python, to help you get started with the challenge.

The first is the Dummy Classifier, which always predicts the most frequent label in the training set. This simple approach serves as a reference point for model performance and achieves an accuracy of approximately 53% on the public Kaggle leaderboard.

The second is a Logistic Regression classifier that uses only the text of each tweet. This baseline performs basic text preprocessing and then transforms the tweets into numerical features using TF-IDF vectorization. The accuracy of this model is approximately 63%.

Both baselines treat each tweet independently, ignoring any temporal order or contextual relationship to the user's other tweets or the broader social network. These models are intended to provide a starting point for experimentation and illustrate how simple methods can perform on the dataset.

7 Useful Python Libraries
To tackle this challenge effectively, you may find the following Python libraries useful:

? Scikit-learn - A versatile library for classical machine learning. Provides tools for preprocessing, feature extraction, and a wide range of models such as logistic regression, decision trees, and ensemble methods.
? PyTorch - A modern deep learning framework that allows you to build and train neural networks, including transformer-based language models. Its ecosystem (e.g., PyTorch Lightning, Hugging Face Transformers) simplifies experimentation and scaling.
? Hugging Face Transformers - Pre-trained transformer models (BERT, RoBERTa, GPT) for feature extraction, text classification, and fine-tuning on your dataset. Great for capturing nuanced language patterns.
? NLTK / SpaCy - Libraries for text preprocessing, tokenization, lemmatization, and other standard NLP tasks. SpaCy is optimized for speed and large-scale processing.
? Gensim / FastText - Tools for unsupervised word embeddings and topic modeling. Useful if you want to generate embeddings without training large models from scratch.
? SentenceTransformers - Provides ready-to-use sentence and document embeddings for semantic analysis, clustering, and classification tasks.
? NetworkX - A library for creating and analyzing graphs. Useful if you want to explore user networks or interactions as a graph structure.
? PyTorch Geometric (PyG) / DGL - Advanced libraries for graph neural networks, ideal if you plan to incorporate social network structures into your model.
